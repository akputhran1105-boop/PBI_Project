# Netflix Content Analysis Dashboard 

# Project Overview
The Netflix Content Analysis Dashboard is an interactive data visualization project developed using Microsoft Power BI. The main objective is to explore and analyze Netflix's content library to identify trends and patterns in movies and TV shows.
The dashboard provides insights into content distribution, popular genres, ratings, release trends, and country-wise availability through interactive charts and visualizations.

# Project Objectives
- Analyze the distribution of Movies and TV Shows on Netflix.
- Identify popular genres and content categories.
- Explore content ratings and their distribution.
- Analyze content release trends over the years.
- Understand country-wise content distribution.
- Present meaningful insights through interactive visualizations.

# Tools & Technologies
- **Power BI Desktop:** Dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Creating calculated measures and KPIs.
- **Data Modeling:** Organizing data for effective analysis.

# Dashboard Visualizations
The dashboard includes the following visualizations:

- **Bar Chart:** Compare content categories and genres.
- **Line Chart:** Analyze content release trends over time.
- **Treemap:** Visualize genre-wise content distribution.
- **Donut Chart:** Show content distribution by categories.
- **Gauge Chart:** Display key performance indicators.
- **KPI Cards:** Highlight important metrics and summary statistics.
- **Slicers:** Enable interactive filtering and exploration of data.

# Key Insights
- Explored the distribution of Movies and TV Shows on Netflix.
- Identified genres with significant content representation.
- Analyzed content release patterns across different years.
- Examined country-wise content distribution.
- Compared content ratings to understand the platform's content classification.

# Project Outcome
Developed an interactive Power BI dashboard that transforms raw Netflix data into meaningful visual insights. This project demonstrates practical skills in data cleaning, data modeling, DAX calculations, KPI development, and interactive data visualization.
